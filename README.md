# To-Do-List
An advanced desktop task management application built with Python and Tkinter. It features task persistence using JSON, dynamic dark mode toggle, priority tagging, live task counting, and regular expression (regex) search capabilities. This project demonstrates desktop application development, event handling, string manipulation, and persistent storage management.

## Features

* Interactive graphical user interface (GUI) built with **Tkinter**
* Seamless Light Mode and Dark Mode theme toggling
* Priority-based task categorization (**High**, **Medium**, **Low**) with visual color coding
* Real-time search and filter functionality powered by **Regular Expressions (Regex)**
* Persistent data storage using **JSON** format to automatically save and load tasks
* Task status tracking with a live task counter
* Safe task deletion with user confirmation prompts and edit functionality

## Technologies Used

* **Python** (Programming Language)
* **Tkinter** (Graphical User Interface Library)
* **JSON** (Data Storage Format)
* **re** (Regular Expression Module for String Operations)
* **os & sys** (File System and Path Management)

## How to Use

1. Ensure **Python 3.x** is installed on your computer.
2. Clone or download this repository to your local machine.
3. Open your terminal or command prompt and run `python main.py` to start the application.
4. Type your task in the input box, select a priority, and click **Add Task**.
5. Use the search bar to filter tasks dynamically using text or regex keywords.
6. Click **Light Mode** / **Dark Mode** to toggle application themes instantly.
7. Select a task to mark it complete, edit its description, or delete it from the list.
